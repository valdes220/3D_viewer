NOMA — локальный запуск туров (для тестов)

1. Положи рядом с index.html:
   start-noma.bat, serve.ps1          — Windows
   start-noma-mac.command             — macOS
2. Туры — в папке tours\ИМЯ\ (tour.json + модель + обложка).
3. Windows: двойной клик по start-noma.bat.
   Mac: правый клик по start-noma-mac.command → Открыть (первый раз).
4. Откроется браузер. Тур: http://localhost:8080/?tour=ИМЯ
   Редактор тура: http://localhost:8080/?tour=ИМЯ&edit
5. Остановить сервер — закрыть окно консоли.

Размер моделей локально не ограничен.
