# Формат `tour.json`

Файл описывает один тур: модель, камеру, точки интереса, оформление и контакты.
Лежит в папке тура рядом с моделью. Все относительные пути считаются от этой папки.

Текущая версия: `noma: 1`, `scene.version: 1`.

## Правила совместимости

1. **Все поля необязательные, кроме `model`.** Тур без `model` не откроется —
   будет понятное сообщение об ошибке.
2. **Неизвестные поля игнорируются.** Старый файл откроется в новой версии,
   новый — в старой (просто без новых возможностей).
3. **Новые поля добавляются только как необязательные.** Обязательных полей
   в формате два: `model` и координаты точки `pos`.
4. **Битая точка не роняет тур.** Точка без корректного `pos` пропускается,
   причина пишется в консоль браузера. Остальные точки работают.
5. **Числа проверяются на тип.** `pos: ["1", "2", "3"]` (строки) — ошибка,
   точка пропускается. `pos: [1, 2]` (два числа вместо трёх) — тоже.

## Минимальный рабочий тур

```json
{
  "noma": 1,
  "model": "scene.glb",
  "scene": { "version": 1, "model": "scene.glb", "pois": [] }
}
```

## Тур с одной точкой

```json
{
  "noma": 1,
  "title": "ЖК «Северный парк»",
  "subtitle": "Корпус 1, вид на двор",
  "accent": "#2F6BFF",
  "cover": "cover.jpg",
  "model": "scene.glb",
  "scene": {
    "version": 1,
    "model": "scene.glb",
    "camera": { "p": [12.4, 3.1, 8.0], "t": [0, 1.5, 0] },
    "startView": { "p": [20, 12, 20], "t": [0, 2, 0] },
    "pois": [
      {
        "id": "flat-1",
        "title": "Двухкомнатная, 62 м²",
        "subtitle": "Корпус 1, 5 этаж",
        "description": "Окна во двор, кухня-гостиная 24 м².",
        "icon": "🏠",
        "color": "#2F6BFF",
        "photos": ["photos/1.jpg", "photos/2.jpg"],
        "price": "8 400 000 ₽",
        "area": "62 м²",
        "specs": "Комнат: 2\nЭтаж: 5 из 12\nОтделка: чистовая",
        "docs": [{ "file": "plan-2k.pdf", "label": "Планировка (PDF)" }],
        "link": { "label": "Забронировать", "url": "https://example.com/book" },
        "pos": [4.2, 1.1, -2.0],
        "cam": { "p": [6.0, 1.6, -2.0], "t": [4.2, 1.1, -2.0] }
      }
    ]
  }
}
```

## Поля верхнего уровня

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `noma` | число | `1` | Версия формата |
| `title` | строка | `''` | Название объекта. Идёт в `<title>` и на обложку |
| `subtitle` | строка | `''` | Подзаголовок |
| `accent` | `#rrggbb` | `#2783DE` | Акцентный цвет интерфейса |
| `cover` | путь | `''` | Обложка, 1920×1080, до ~500 КБ |
| `model` | путь | — | **Обязательно.** Имя файла модели в папке тура |
| `hdri` | путь | — | `.hdr` / `.exr` для отражений |
| `lock` | hex-строка | `''` | SHA-256 от `"noma:" + пароль`. Не защита, см. ниже |
| `stages` | массив | — | Состояния модели (см. ниже) |

### `cta` и `site` — кнопки

```json
"cta":  { "label": "Связаться", "url": "https://t.me/manager" },
"site": { "label": "Сайт проекта", "url": "https://example.com" }
```

Пустой `url` — кнопки нет.

### `lead` — приём заявок

```json
"lead": {
  "label": "Узнать цену",
  "wa": "79001234567",
  "tg": "@manager",
  "tel": "+79001234567",
  "email": "sales@example.com",
  "key": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
}
```

- `key` — ключ Web3Forms. Без него форма предложит письмо через почтовое приложение.
- Минимум одно из полей должно быть заполнено, иначе кнопки заявки не будет.

### `legal` — юридическое

```json
"legal": { "operator": "ООО «Ромашка»", "policy": "policy.html" }
```

`policy` пустой — откроется встроенный шаблон политики.

### `analytics`

```json
"analytics": { "ym": "12345678", "hook": "", "note": true }
```

`ym` — номер счётчика Яндекс.Метрики. `hook` — URL, куда отправлять события
(`POST`, JSON). `note: false` скрывает уведомление о сборе данных.

## `scene` — сцена

| Поле | Тип | Описание |
|---|---|---|
| `version` | число | `1` |
| `model` | строка | Дублирует имя модели |
| `camera` | `{p, t}` | Камера при открытии |
| `startView` | `{p, t}` | Стартовый ракурс («общий план») |
| `keys` | массив | Ключи пролёта камеры |
| `slots` | массив из 3 | Сохранённые ракурсы, `null` — пусто |
| `path` | объект | Настройки пролёта |
| `anim` | объект | Анимации модели |
| `view` | объект | Освещение, погода, материалы |
| `pois` | массив | Точки интереса |
| `groups` | массив | **Новое.** Корпуса и зоны |

### Векторы камеры

```json
"camera": { "p": [x, y, z], "t": [x, y, z] }
```

`p` — позиция камеры, `t` — точка, на которую она смотрит. Ровно три конечных числа.
Строки, `null`, `NaN`, массивы другой длины — ошибка, значение отбрасывается.

### `scene.groups` — корпуса и зоны

**Новое поле.** Необязательное. Если его нет, селектор в интерфейсе не показывается
и тур работает как раньше.

```json
"groups": [
  {
    "id": "k1",
    "title": "Корпус 1",
    "cam": { "p": [30, 12, 0], "t": [0, 4, 0] },
    "pois": ["flat-1", "flat-2"]
  },
  {
    "id": "k2",
    "title": "Корпус 2",
    "cam": { "p": [-30, 12, 0], "t": [0, 4, 0] },
    "pois": ["flat-3"]
  }
]
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Стабильный идентификатор, латиница и цифры |
| `title` | да | Подпись на кнопке |
| `cam` | нет | Ракурс для перехода при выборе корпуса |
| `pois` | нет | Список `id` точек этого корпуса |

Поведение:

- Выбор группы плавно переводит камеру в `cam` (если задан).
- Точки, которых нет в `pois`, скрываются с карты.
- Если `pois` пустой, используется поле `group` у самой точки: точка попадает
  в группу, если её `group` совпадает с `id`.
- Если `id` точек не совпадают ни с чем, фильтрация не сработает — проверьте
  идентификаторы.

> **Не путать со `stages`.** `stages` — это переключение состояний модели
> (этапы стройки, варианты отделки). `groups` — это навигация по объекту.

### `scene.pois` — точки интереса

| Поле | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | строка | генерируется | Идентификатор, используется в `groups` |
| `title` | строка | `Точка` | Название в карточке |
| `subtitle` | строка | `''` | Подзаголовок |
| `description` | строка | `''` | Описание |
| `icon` | emoji | `📍` | Значок на карте |
| `color` | `#rrggbb` | `#2783DE` | Цвет значка |
| `pos` | `[x,y,z]` | — | **Обязательно.** Позиция в сцене |
| `cam` | `{p, t}` | рядом с точкой | Ракурс при клике |
| `photos` | массив путей | `[]` | Фотографии в карточке |
| `image` | путь | — | Старое поле, работает как `photos: [image]` |
| `price` | строка | `''` | Цена, показывается плашкой |
| `area` | строка | `''` | Площадь |
| `specs` | строка | `''` | Характеристики, по строке «Ключ: значение» |
| `plan` | `{file, label}` | — | PDF-планировка (старое поле, **работает**) |
| `docs` | массив | `[]` | **Новое.** Несколько документов |
| `link` | `{label, url}` | — | Своя кнопка |
| `group` | строка | `''` | **Новое.** Принадлежность к корпусу |
| `stay` | число | `8` | Секунд на остановке в экскурсии |
| `tod` | число | — | Время суток на остановке |
| `anim` | массив | — | Клипы анимации на остановке |
| `skip` | bool | `false` | Исключить из экскурсии |

Старое `plan` и новое `docs` можно использовать одновременно — покажутся оба.

```json
"docs": [
  { "file": "plan-2k.pdf", "label": "Планировка (PDF)" },
  { "file": "presentation.pdf", "label": "Презентация проекта" }
]
```

### `scene.triggers` — кнопки анимации

**Новое поле.** Необязательное. Маленькие точки на модели, запускающие клип
анимации при нажатии. Не путать с `pois`: у кнопки нет карточки, только действие.

```json
"triggers": [
  {
    "id": "door-main",
    "pos": [4.2, 1.1, -2.0],
    "anim": ["DoorOpen"],
    "label": "Открыть дверь"
  },
  {
    "id": "lights",
    "pos": [1.0, 2.4, 0.5],
    "anim": ["LightOn", "LampGlow"]
  }
]
```

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | нет | Идентификатор, генерируется если нет |
| `pos` | **да** | Координаты на модели `[x, y, z]` |
| `anim` | нет | Имена клипов. Можно строкой или массивом |
| `label` | нет | Всплывающая подсказка и текст в строке состояния |
| `color` | нет | Цвет точки, по умолчанию `#8E8E93` |

Поведение:

- **В орбите** кнопка видна всегда как мелкая полупрозрачная точка (14 px).
- **В пешеходе** проявляется плавно, только если камера близко (до ~8 м),
  смотрит в её сторону и её не перекрывает геометрия.
- Нажатие запускает клипы из `anim` с начала. Повторное нажатие перезапускает.
- Клипы играют один раз (`LoopOnce`) и останавливаются на последнем кадре.
- Если клипа нет в модели, кнопка остаётся, но при нажатии пишет в статус,
  что анимация не найдена.

Кнопки добавляются в редакторе: вкладка «Точки» → блок «Кнопки анимации» →
«Поставить кнопку на модель», затем клик по модели и выбор клипа в списке.

### `scene.keys` — пролёт камеры

```json
"keys": [
  { "p": [10, 5, 10], "t": [0, 1, 0], "d": 4, "tod": 9 },
  { "p": [0, 8, 20], "t": [0, 2, 0], "d": 4 }
]
```

`d` — время в секундах до следующего ключа.

### `scene.view` — освещение и погода

```json
"view": {
  "light": "sun",
  "bg": "sky",
  "mat": "orig",
  "tod": 14.5,
  "az": 180,
  "cloud": 0.4,
  "shadows": true,
  "ground": true,
  "weather": "clear",
  "exposure": 1.0
}
```

Некорректные числа в этом объекте отбрасываются, остальные настройки применяются.

### `stages` — состояния модели

```json
"stages": [
  { "label": "Готовый дом", "file": "", "mode": "replace", "fx": "dust", "fxPower": "calm" },
  { "label": "Каркас", "file": "frame.glb", "mode": "replace", "fx": "dust", "fxPower": "calm" }
]
```

Пустой `file` у первого элемента — текущая модель.

## Ресурсы: изображения и документы

Пути разрешаются **относительно папки тура**:

| В `tour.json` | Результат |
|---|---|
| `photos/1.jpg` | `tours/mytour/photos/1.jpg` |
| `/shared/logo.png` | `https://site.ru/shared/logo.png` |
| `https://cdn.ru/a.jpg` | как есть |
| `data:image/jpeg;base64,...` | как есть (поддерживается, но раздувает файл) |

`data:image/*` работает для обратной совместимости со старыми турами. Новые
изображения так лучше не добавлять: base64 внутри JSON увеличивает его в 1,4 раза
и файл скачивается при каждом открытии.

### Разрешённые схемы URL

`http`, `https`, `tel`, `mailto`, `tg`, `whatsapp`, `viber`, `blob`, `data:image/*`.

Всё остальное отклоняется: `javascript:`, `data:text/html`, `vbscript:` и т. п.
Проверка — в `src/tour-io.js`, функция `isSafeUrl`.

## Про пароль (`lock`)

Поле `lock` содержит SHA-256 от строки `"noma:" + пароль`. Пароль проверяется
в браузере.

Это **не защита**. Хеш лежит в публичном файле, соли нет, подбирается офлайн за
секунды для простого пароля. Модели и данные доступны по прямой ссылке всем, кто
знает URL. Поле защищает только от случайного открытия редактора.

Для настоящей защиты нужен сервер с авторизацией — это отдельная задача, на GitHub
Pages она не решается.
